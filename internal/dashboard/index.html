Get Warden in front of your agent

You'll see traffic light up in minutes. Follow the steps — copy, paste, watch it work.
Prevent — secrets & bad egress at the edge Detect — DLP & MCP threats in bodies Prove — every decision, signed
Step 2 of 825%
1 · Generate the proxy CA
Bake it once — your agent trusts this CA so Warden can terminate TLS and inspect HTTPS.
scripts/gen-certs.sh
OUT_DIR=deploy/compose/certs ./scripts/gen-certs.sh # for the compose recipes
2 · Start Warden
Recipes boot allow-all so you SEE every call first, then tighten. Pick how you run it:
docker compose -f deploy/compose/docker-compose.ethos.yml up
Agent → http://localhost:3000 · Warden dashboard → http://localhost:9091/dashboard/. Recipes also ship for hermes, openclaw and zeroclaw — swap the compose file.
warden run --listen 127.0.0.1:8080 --ca-cert certs/proxy-ca.crt --admin-listen 127.0.0.1:9090
Dashboard → http://127.0.0.1:9090/dashboard/
kubectl apply -f deploy/k8s/…
Run Warden as a sidecar. Ship a default-deny NetworkPolicy so the agent's only egress is the Warden sidecar — no route to the internet otherwise.
3 · Route your agent through Warden
Structural isolation — the agent has no direct internet; its only way out is Warden.
HTTPS_PROXY=http://worker:8080 HTTP_PROXY=http://worker:8080 NODE_USE_ENV_PROXY=1 # Node fetch ignores the proxy without it NODE_EXTRA_CA_CERTS=/certs/proxy-ca.crt # trust the CA (also below) SSL_CERT_FILE=/certs/proxy-ca.crt REQUESTS_CA_BUNDLE=/certs/proxy-ca.crt
Put the agent on an internal-only network — no route out except Warden.
4 · See your first request
This is the aha moment. Fire any request from your agent and watch it appear.
Waiting for your agent's first request…
✅ First request received — api.openai.com · allow · 42ms
5 · You're observing (monitor mode)
Nothing is blocked yet. Warden is watching. Once you see what your agent reaches, tighten the policy and switch to Enforce.
Monitor
Every call logged & signed. Nothing blocked.
→
Enforce
Allow/deny + DLP + MCP rules apply. Bad egress stopped.
6 · Add your secrets (optional)
Store a placeholder → value so your agent never holds a real key. Warden injects the real value at the edge.
7 · Set guardrails
Add allowed destinations + DLP data-class rules, then flip Monitor → Enforce.
8 · Wire alerts (optional)
Connect Slack/webhook and add a rule to get notified on blocks & threats.
(Fleet) Connect the control plane — workers trust the CP via its CA + a token; the central dashboard lives at https://localhost:7070/dashboard/.
